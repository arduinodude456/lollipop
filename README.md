# What is LOLLIPOP
lollipop is an alternative UI for Kobo devices. It replaces Nickel. Its designed to bbe as simple as possible. Debloated. No ads. Just a simple launcher, bookshelf and library (archive.org)

Just download KoboRoot.tgz from releases and put it into (eReader)/.kobo dir.
# Supported devices
* Kobo Libra Colour
* Kobo Clara Colour
# Languages
* German
* English (coming soon)
